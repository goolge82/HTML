1. What is HTML?

HTML stands for HyperText Markup Language.

HTML is used to create the structure of a web page.

- HyperText: Text that contains links to other pages or resources.
- Markup: We use tags to define and organize content.
- Language: A set of rules used to write instructions.
  • <html> is the root element.
  • <head> contains webpage information.
  • <title> displays the title in the browser tab.
  • <body> contains visible webpage content.
  • </html> indicates the end of the HTML document.

2. Meta Tags

  • Meta tags are HTML elements used to provide additional information (metadata) about a webpage to browsers, search engines and other services.
  • Meta means information about information.
  • Meta tags are placed inside the <head> section of an HTML document.
  • Meta tags are generally not displayed directly on the webpage.
  • They help browsers understand webpage settings and provide information about the page.
Meta Tag Purpose
<meta charset="UTF-8"> Specifies the character encoding of the webpage
<meta name="viewport"> Controls webpage layout on different screen sizes
<meta name="description"> Provides a short description of the webpage
<meta name="keywords"> Specifies keywords related to the webpage
<meta name="author"> Specifies the author of the webpage

3. Paired Tags (Container Tags)

HTML tags are classified into two types based on whether they have a closing tag or not.

Meaning: Paired tags contain both an opening tag and a closing tag. The content is written between these two tags.

  • Opening tag: <tagname>
  • Closing tag: </tagname>

4. Unpaired Tags (Empty/Void Tags)

Unpaired tags do not require a closing tag. They do not wrap content between opening and closing tags.

10. HTML Lists

1. Ordered List (<ol>)

  • Displays items in a numbered sequence.
  • The order of items is important.
  • Uses <li> to define each list item.

2. Unordered List (<ul>)

  • Displays items with bullet points.
  • The order of items is not important.
  • Uses <li> to define each list item.

3. Description List (<dl>)

  • Displays terms along with their descriptions.
  • Mainly used for definitions or explanations.
  • Uses <dt> for the term and <dd> for its description.

<dl>
    <dt>HTML</dt>
    <dd>HyperText Markup Language</dd>

    <dt>CSS</dt>
    <dd>Cascading Style Sheets</dd>
</dl>
Tag Purpose
<ol> Creates an ordered list
<ul> Creates an unordered list
<li> Defines a list item
<dl> Creates a description list
<dt> Defines a term or name
<dd> Defines a description of a term

Additional Attributes in List Tags

Attribute Purpose
type Specifies numbering or bullet style
start Specifies the starting number in an ordered list
reversed Displays ordered list numbers in reverse
value Specifies a particular number for an ordered list item
